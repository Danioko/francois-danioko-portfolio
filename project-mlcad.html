APERÇU DE L’APPLICATION

MLCad v1.0 en situation réelle

LE BESOIN

Faciliter l’accès à l’information foncière

MLCad structure et valorise des données cadastrales dans une interface cartographique consultable depuis un navigateur. Le modèle est pensé pour être réutilisable et adaptable à plusieurs sites ou localités.

Fonctionnalités

Recherche et identification de parcelles, navigation cartographique, consultation des attributs, gestion de couches, localisation et édition de fiches parcellaires.

MA CONTRIBUTION

De la donnée SIG à l’application Web

Conception fonctionnelle, préparation et structuration des données dans QGIS, export Web, personnalisation HTML/CSS/JavaScript, intégration des outils de consultation et publication avec GitHub Pages.

Technologies

QGIS • QGIS2Web • Leaflet • JavaScript • HTML/CSS • Proj4 • GitHub Pages
